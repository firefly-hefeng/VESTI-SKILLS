# VESTI Skill 定向能力验证预注册

- 状态：**LOCKED**
- 锁定时间：2026-08-16T13:10:24+08:00
- 实验编号：`vesti-file-search-targeted-skill-v1`

## 目的与边界

本实验用于回答一个窄问题：在使用完全相同的 VESTI MCP、模型、数据库和输出格式时，冻结的文件定位 Skill 能否改善高歧义、多约束历史文件定位任务。

这是一项事前定义、小规模、探索性的功能合同对齐验证。语料为合成数据，并有意富集完整条件核验、项目隔离、同一会话求交、最小文件集合与证据不足拒答等 Skill 职责场景。它不是自然用户查询的抽样，不能估计产品在总体任务分布中的平均提升，也不与既有实验合并。

## 固定设计

- 16 个任务，8 个独立 concept；中文 8 题、英文 8 题。
- 四类任务各 4 题：三重约束单文件、最小多文件组、项目隔离/跨项目、关系型困难负例。
- 12 个正例、4 个负例；所有任务和失败结果都必须报告。
- 每题运行两个配对臂，每臂一次，共 32 次 Agent 调用。
- 模型固定为 `gpt-5.6-luna`，每次使用新的 ephemeral Codex 进程和同字节数据库副本。
- B 组 `modern-none` 与 D 组 `modern-vesti-v3` 使用相同的四个只读 MCP 工具；仅 D 组加载冻结 Skill。
- 题目、gold、评分器、调度顺序和哈希在首次模型调用前锁定。看到结果后不删题、不补题、不换 seed、不修改主指标。

## 任务构造

每个正例都有一个完整满足用户条件的 supporting session，以及三个只满足三项条件中两项的干扰 session。负例中的条件分别或成对存在，但没有任何单个 session 同时满足全部条件。用户题面不包含目标路径、session ID、basename 或“求交、最小集合、拒答”等解题策略。

## 对照与处理

| 组别 | MCP | Skill | 其他设置 |
|---|---|---|---|
| B：仅检索层消融 | 相同的四个 VESTI 工具 | 无 | 与 D 完全相同 |
| D：完整配套方法 | 相同的四个 VESTI 工具 | 冻结 V3 Skill | 与 B 完全相同 |

产品仍以“MCP 证据检索层 + Skill 决策核验层”的配套方法交付；这里保留 B 组只是为了隔离 Skill 在同一 MCP 上的增量。

## 指标与判定

唯一主指标是严格任务成功率。正例必须同时满足：返回完整且唯一的 gold 文件集合、没有额外文件、项目正确、每个文件引用合法 supporting session，并标记为历史证据；负例必须返回 `answerable=false` 且 `files=[]`。

同时报告：

- 12 个正例的严格成功率与零额外文件率；
- 4 个关系型困难负例的实际错误文件返回率；
- D 相对 B 的配对胜、负、平和百分点差；
- 按 8 个 concept 聚类的 Bootstrap 区间与 exact McNemar 检验，均只作小样本描述；
- 工具调用、输入 Token 和端到端时长，作为描述性工程指标。

预先定义的工程通过条件为：D 至少答对 13/16；D-B 至少为 +12.5 个百分点，即净多答对至少 2 题；D 的正例成功率不得低于 B；D 的困难负例实际错误文件率不得高于 B。未达到时同样保留并报告结果。
