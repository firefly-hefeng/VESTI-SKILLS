# VESTI MCP + Skill 功能合同对齐验证

- 实验日期：2026-08-16
- 实验范围：16 个事前冻结的高歧义、多约束任务
- 对照方式：相同 MCP，仅切换冻结 Skill
- 实验用途：检查 Skill 的四项直接职责是否按设计工作

## 结论

在 16 个功能合同对齐任务中，完整配套组答对 **14/16（87.5%）**，相同 MCP 的无 Skill 组答对 **12/16（75.0%）**，观察差为 **+12.5 个百分点**。配对结果为 **2 胜、0 负、14 平**：Skill 组多答对两题，没有把原本正确的题答错。12 个正例全部严格通过，文件集合、项目和支撑会话均正确。

这两道净改善分别来自：

- 多文件任务：无 Skill 组把三个相似会话中的文件全部合并，返回 6 个文件；Skill 组只保留完整锚点会话中的 2 个标准答案文件。
- 关系型困难负例：三个条件分别能在历史中找到，但没有同一会话同时满足；无 Skill 组返回了错误文件，Skill 组正确拒答。

实验达到事前定义的工程通过条件：完整组至少 13/16、净改善至少 2 题、正例不回退、困难负例错误文件不增加。

## 设计

实验在首次模型调用前锁定了 16 道题、gold、评分器、模型、调度顺序和全部哈希。两组都使用 `gpt-5.6-luna`、同一份数据库和相同的四个只读 VESTI MCP 工具；唯一处理变量是是否加载冻结的 V3 文件定位 Skill。

| 题型 | 数量 | 主要考查点 |
|---|---:|---|
| 三重约束单文件 | 4 | 不把只满足部分条件的高排名候选当答案 |
| 最小多文件组 | 4 | 从同一支撑会话取最小完整集合，不跨会话做并集 |
| 项目隔离 / 跨项目 | 4 | 排除同名文件和错误项目中的近似记录 |
| 关系型困难负例 | 4 | 条件分别存在但关系不成立时拒答 |

语料共有 8 个独立 concept、62 条合成会话，中文和英文各 8 题。12 个正例各自包含 1 个完整支撑会话和 3 个部分匹配干扰会话；4 个负例的条件分别或成对出现，但不存在满足全部条件的会话。所有 16 题和全部失败均进入结果，没有事后删题、补题或换 seed。

## 主要结果

| 指标 | 同一 MCP、无 Skill | MCP + 冻结 Skill | 变化 |
|---|---:|---:|---:|
| 严格任务成功率 | 12/16，75.0% | 14/16，87.5% | **+12.5pp** |
| 正例严格成功率 | 11/12，91.7% | 12/12，100.0% | **+8.3pp** |
| 正例零额外文件率 | 11/12，91.7% | 12/12，100.0% | **+8.3pp** |
| 困难负例正确拒答 | 1/4，25.0% | 2/4，50.0% | **+25.0pp** |
| 困难负例实际错误文件 | 3/4，75.0% | 2/4，50.0% | **-25.0pp** |
| 配对胜 / 负 / 平 | — | 2 / 0 / 14 | 无回退题 |

严格成功要求正例的文件集合、项目、支撑会话和历史标记全部正确，并且没有额外文件；负例必须返回 `answerable=false` 和空文件数组。

## 分题型结果

| 题型 | 无 Skill | 冻结 Skill | 配对变化 |
|---|---:|---:|---:|
| 三重约束单文件 | 4/4 | 4/4 | 0 胜 / 0 负 |
| 最小多文件组 | 3/4 | 4/4 | 1 胜 / 0 负 |
| 项目隔离 / 跨项目 | 4/4 | 4/4 | 0 胜 / 0 负 |
| 关系型困难负例 | 1/4 | 2/4 | 1 胜 / 0 负 |

这说明本轮增益集中在 Skill 的两个直接职责：抑制跨会话候选并集，以及在完整关系证据不存在时拒答。单文件和项目隔离题中，两组都达到满分，存在天花板，不能用来证明 Skill 的额外增益。

### 当前覆盖边界与下一步

16 个任务中有 14 个严格通过。尚未覆盖的是两个英文关系型负例：主题短语、API / 方法名和错误码分散在不同或部分匹配的会话里，Agent 仍把满足其中两项的会话解释成完整证据并返回文件。当前 Skill 已改善关系核验，但“所有必要条件必须在同一会话中明确成立”仍需进一步强化。

后续改进应聚焦证据合同本身：让 MCP 返回完整短语覆盖、必要 token 覆盖率和 matched snippet；Skill 只允许使用同时覆盖全部必要条件的 supporting session。不能在本数据集上修改后重跑并继续称为独立验证。

## 建议引用口径

可以说：

> 在事前冻结的 16 个 Skill 功能合同对齐任务中，MCP + Skill 完整组达到 87.5%，相同 MCP 的无 Skill 组为 75.0%，观察提升 12.5 个百分点；配对为 2 胜、0 负、14 平。正例达到 12/12，困难负例错误文件由 3/4 降至 2/4。

这是一项事前冻结的小规模功能合同验证。8 个 concept 的聚类 Bootstrap 95% CI 为 **[0.0,+31.3] 个百分点**，exact McNemar `p=0.50`。它支持“在这些职责场景中观察到正向工程增量”，不用于估计自然用户任务上的总体平均提升，也不与其他版本合并计算综合提升率。
