# VESTI MCP + Skill 实验汇报速览

完整对外数据卡见[实验成果摘要](../PUBLIC-RESULTS-ZH.md)，历史版本与全部统计见[完整技术审计](../INTEGRATED-METHOD-RESULTS-ZH.md)。

## 一句话说明

VESTI 把 MCP 历史证据检索和 Skill 决策核验串成一条文件定位链路：先从历史 AI 会话中找候选文件，再核对项目、文件名和支撑会话，最后返回最小可信文件集；证据不足时不猜。

## 一分钟口头稿

VESTI 解决的不是普通文件搜索，而是用户只记得一段历史协作线索时，AI 能不能找回当时讨论过的本地文件。我们把 MCP 和 Skill 作为一套配套方法：MCP 从历史会话中召回文件、项目和支撑会话，Skill 负责核对完整线索、收敛候选，并在没有证据时拒答。

实验是分层做的。确定性检索测试中，66 个计分任务的主任务成功率从 81.8% 提高到 100%，中位工具调用从 11 次降到 1 次。文件名定位专项从 33.3% 提高到 100%，12 个任务全部通过。

早期压力测试发现了跨会话合并候选的问题。我们据此重写了候选求交和会话锚点核验。V3 在 24 个新回归任务中达到 95.8%，18 个正例全部精确通过，没有额外文件；困难负例中的实际错误文件返回也在冻结压力子集中由 30% 降到 0%。

为了单独检查 Skill 的职责，我们又事前冻结了 16 个高歧义、多约束任务，两组使用完全相同的 MCP，只切换 Skill。完整组为 14/16，无 Skill 组为 12/16，观察提升 12.5 个百分点，配对为 2 胜、0 负、14 平；正例达到 12/12，困难负例错误文件由 3/4 降到 2/4。这是一组小规模功能合同验证，适合说明 Skill 在最小文件集合和关系证据拒答上的工程价值。

## 三条结论

1. 已确认：检索执行层补齐了文件名反查，当前冻结基准中达到 100%，调用次数也明显减少。
2. 工程证据支持：在 16 个事前定义的 Skill 功能合同对齐任务中，同一 MCP 下观察到 +12.5pp，且没有回退题。
3. 仍待确认：该结果来自合成且有意富集的小样本，尚未证明 Skill 在自然任务总体上都能提高准确率；需要新的正式盲测。

## 口径边界

- pp 表示百分点，CI 表示置信区间。
- 100% 指 66 个计分的冻结合成检索任务，不代表所有真实用户任务都能达到 100%。
- 93.1% 与 84.7% 是早期事后完整方法直接比较，差异的总体 CI 跨过 0。
- 30% → 0% 是正式实验中的实际错误文件返回诊断，不是生产环境总体误报率承诺。
- V3 是 24 个首次运行前冻结的针对性快速回归，不能替代大规模确认性实验。
- 87.5% vs 75.0% 来自 16 个事前定义、同一 MCP 仅 Skill 开 / 关的定向能力任务；全量任务和失败均已报告，但它不是自然用户总体效果估计。
- 这 16 题的 95% CI 下界为 0，McNemar `p=0.50`，不能表述为“总体显著提升”。
- 不同版本、数据集和实验用途不同，不能把它们合并成一个“综合提升率”。

## 建议的最后一句

当前证据已经说明 VESTI 能把历史会话变成可用的文件证据，并明显补齐文件名反查；在 Skill 专门负责的高歧义、多约束场景中，完整方法还观察到 12.5 个百分点的正向增量。这个结果值得继续验证，但仍需要真实项目和更大盲测才能判断自然任务总体效果。
