# VESTI MCP + Skill 实验成果摘要

更新时间：2026-08-17

## 方法概览

VESTI 把 MCP 历史证据检索和 Skill 决策核验组合成一套文件定位方法。MCP 负责从历史 AI 会话中召回文件、项目和支撑会话；Skill 负责核对完整线索、排除部分匹配，并将候选收敛为最小可信文件集。

## 核心结果

| 能力 | 实验结果 | 结论 |
| --- | ---: | --- |
| 历史文件检索 | **100.0% vs 81.8%**，提升 **18.2pp** | 66 个计分任务全部通过，95% CI 为 `[+17.4,+19.0]`；中位工具调用由 11 次降至 1 次 |
| 文件名反查 | **100.0% vs 33.3%** | 12 个文件名定位任务全部通过，McNemar `p=0.0078` |
| 端到端完整方法 | **93.1% vs 84.7%** | 72 个任务中观察到 **+8.3pp**，说明完整链路具有正向工程信号 |
| V3 精确回归 | **23/24，95.8%** | 18 个正例全部精确定位，项目和证据会话均正确，没有额外文件 |
| Skill 功能合同对齐 | **87.5% vs 75.0%** | 同一 MCP 仅切换 Skill，完整方法多答对 2 题，配对为 **2 胜、0 负、14 平** |
| 困难负例安全控制 | 错误文件 **9/30 → 0/30** | 冻结压力测试中，实际错误文件返回率由 30% 降至 0% |

`pp` 表示百分点。

## Skill 带来的直接变化

16 个功能合同对齐任务专门覆盖完整条件核验、最小多文件集合、项目隔离和关系证据拒答。两组使用相同模型、数据库、输出格式与四个只读 MCP 工具，唯一差别是是否加载冻结 Skill。

- 严格成功率由 **12/16 提高到 14/16**；
- 正例由 **11/12 提高到 12/12**；
- 正例零额外文件由 **11/12 提高到 12/12**；
- 困难负例中的错误文件由 **3/4 降到 2/4**；
- 工具调用总量由 **142 降到 134**。

两个新增成功分别体现了 Skill 的核心职责：一是避免把多个相似会话中的文件直接合并，二是在完整关系证据不存在时拒绝返回看似相关的文件。

## 推荐汇报口径

> VESTI MCP + Skill 配套方法把历史 AI 会话转化为可追溯的文件证据。冻结合成基准中，检索执行层主任务成功率由 81.8% 提高到 100%，文件名定位由 33.3% 提高到 100%。修订后的 V3 在 24 个新回归任务中达到 95.8%，18 个正例全部精确定位且没有额外文件。在进一步的功能合同对齐验证中，同一 MCP 加载 Skill 后，严格成功率由 75.0% 提高到 87.5%，配对结果为 2 胜、0 负、14 平。

## 适用范围

这些数据来自版本化合成基准，用于验证历史文件定位机制。文件名定位结果是 12 题专项分层；72 题端到端比较的总体置信区间包含 0；16 题功能合同实验是小规模、单模型的职责场景验证，95% CI 为 `[0.0,+31.3]`，McNemar `p=0.50`。因此可以表述为“观察到正向工程增量”，不应外推为所有自然用户任务上的总体显著提升。
