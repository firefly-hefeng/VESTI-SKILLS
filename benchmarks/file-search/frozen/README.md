# Frozen Agent inputs

`vesti-memory-skill.md` preserves the semantic Skill text used by the
2026-08-15 four-arm Agent experiment. The original working-tree file contained
mixed LF/CRLF line endings and had SHA-256
`9ea2fbb084cd5191709c9cb852d36a7d664cae1055cf464e3db4825ec86066a8`.

The version stored here is normalized to LF and has SHA-256
`001fe3bd0c80debec8ea0596d05c71806afa4880f940ef38233eeaa539444cca`.
Its decoded text is identical to the experimental input; only newline bytes
differ. The original byte hash remains authoritative for matching the result
manifest and prompt hashes.
