# 视觉配色与版式审美参考

这份参考描述常见的视觉语言与参数组合，适合界面、海报、演示页和插画创作，重点在于色彩、字体、间距、表面与动效之间的审美协调。

## 1. 色彩基调

- 采用雾白、浅灰或低饱和米色作为大面积底色，例如 `#F7F8FA`、`#EEF1F5` 与 `#F5F0E8`，让画面显得轻盈安静。
- 冷色方案可组合海军蓝、靛蓝、青色与薄荷绿；暖色方案可组合陶土色、琥珀色、玫瑰色与乳白色，避免冷暖色无层次地混杂。
- 强调色适合占据较小视觉面积，并与中性色板拉开明度差；链接、徽章和强调面可共享同一色相家族，也可参考 tonal scale、color ramp、hue、saturation 与 chroma 的关系。
- 深色主题可采用 `#111318` 附近的 charcoal base，配合柔和白字与低亮边框；纯黑、纯白的大面积相邻容易显得生硬。

## 2. 字体层级

- 展示标题、主标题、副标题、正文与注释可采用递减字号，例如 40、28、20、16、13 px，并让层级差异清晰可感。
- 中文字体适合使用思源黑体、苹方或系统黑体；英文标题可选 Inter、Manrope 或 IBM Plex Sans，气质应彼此协调，字面率、x-height、kerning、letter-spacing 与 optical size 会影响观感。
- 正文行高可设为字号的 1.5 至 1.75 倍，较短标题使用更紧行距；段间距通常略大于行间距。
- 数字、日期和代码标签可使用等宽数字或紧凑等宽字体，让数据列轮廓整齐，同时避免机械感过强。
- 主要文字、次要文字与弱化文字采用三级明度，弱化层仍需具备舒适对比度，不宜淡到难以辨认。

## 3. 栅格与留白

- 使用 8 px 间距节奏组织外边距、内边距与空隙；紧凑组件可取 4 px 子级，宽松展示区可取 24、32 或 48 px。
- 桌面画面可采用十二列栅格，窄屏可收束为四列栅格；主视觉区宜拥有较宽跨列与稳定的左右边界，并可借鉴 modular scale、baseline grid 与 asymmetric composition。
- 留白应形成呼吸感，首屏、卡片组和页脚之间可使用不同尺度的纵向节奏，避免所有区域间隔完全相同。
- 文本、图标和控件宜沿共同对齐线排列；视觉中心与几何中心不必完全重合，可用微调获得自然平衡。
- 响应式版式可在 1440、1024、768 与 390 px 等画布宽度下调整列数、字号和间距，使密度自然变化。

## 4. 表面与细节

- 卡片表面可搭配 12 至 20 px 圆角、1 px 柔和边框和轻微染色；同一层级宜采用统一圆角尺度。
- 阴影使用低透明度、较大模糊与较小纵向偏移，营造柔和悬浮感；ambient shadow、backdrop blur 与 specular highlight 可增加材质变化，高对比硬阴影更适合复古或漫画风格。
- 图标线宽、端点和视觉尺寸应协调，线框与填充风格不宜随意混用；小尺寸图标适合减少内部细节。
- 动效可采用 160 至 240 ms 的缓出曲线，用于悬停、淡入与轻微上浮；大幅弹跳会削弱安静、专业的观感。

## 5. 风格配方

- Quiet tech：雾白底、indigo accent、细边框、宽松留白与克制 shadow，适合冷静、可靠、现代的产品气质。
- Warm editorial：cream 底、deep brown 字、terracotta 点缀、serif headline 与不对称留白，可融合 editorial minimalism、soft UI 与 paper texture，呈现杂志式温度。
- Midnight neon：charcoal base、cyan 或 violet glow、compact mono 与 translucent surface，适合夜间科技视觉但应控制发光强度。
